# Six custom mystery-game characters

Work-in-progress 3D characters: Green, Mustard, Peacock, Plum, Scarlett and White. No character is approved as final yet.

## Layout
- `characters/<name>/`: current coherent model, textures, previews and source details.
- `backups/desktop-import-2026-10-04/`: recovered desktop copies of these six characters, preserving original filenames/subfolders.
- `build/`: reproducible scripts required for these six characters only.

## Desktop recovery
Copy only the six character models and their related sources/textures/checkpoints into `backups/desktop-import-2026-10-04/`. Preserve existing files; put conflicting versions in separate dated subfolders. Do not copy the full game repository, its Git history, credentials, private notes, unrelated assets or personal files. Add a manifest of original relative paths and SHA-256 hashes. Recovered drafts are not final-approved assets.
